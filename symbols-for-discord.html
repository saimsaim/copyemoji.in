How to Use on Discord

Status: Custom Status → paste 1-3 symbols, e.g. ☾ studying or ♪ now playing. Nickname: Server profile → Edit → ★ Nova or Nova ✦. About Me: divider stacks like ─ ✦ ─ or ♪ ━━━━ ♪. Keep 2-4 symbols max or names get truncated on mobile.

Why Unicode beats custom emoji: custom :name: breaks outside its server without Nitro. Everything on this grid is plain text — it pastes into any server, DM, Instagram bio or game tag. Need emoji meanings too? See Symbols, Heart Emojis, Aesthetic Emojis and Kaomoji.
